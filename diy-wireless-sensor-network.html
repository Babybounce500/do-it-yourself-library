Dezentrales Mesh-Netzwerk für Umweltdaten

Kapitel 1: Sensor Hardware & Microcontroller

Komponenten (€50-100 pro Node):

  • ESP32: WiFi + Bluetooth, €3-5
  • DHT22: Temperatur/Humidity, €2
  • MQ135: Air Quality, €5
  • SoilMoisture Sensor: €1

Kapitel 2: Wireless Protokolle

  • WiFi: Reichweite 50m, Power 80mA
  • LoRaWAN: 10km, 5mA (Low Power)
  • Zigbee: Mesh, 100m, 15mA
  • BLE: 100m, 5mA

Kapitel 3: Arduino Code für Sensor Reading

#include "DHT.h" DHT dht(DHTPIN, DHT22); float temp = dht.readTemperature(); Serial.println(temp);
