🌐 MQTT Home Automation

Dezentrales Messaging für Smart Homes

Kapitel 1: MQTT Broker Setup

MQTT = Message Queuing Telemetry Transport

  • Mosquitto: Leichtester Broker (Raspberry Pi)
  • HiveMQ: Enterprise-ready
  • EMQX: Scalable
Installation: sudo apt install mosquitto mosquitto-clients

Kapitel 2: Topic Architecture

Hierarchische Topic-Struktur:

home/living_room/lights/brightness home/living_room/lights/power home/bedroom/temperature/current home/bedroom/humidity/current

Kapitel 3: IoT Devices verbinden

  • ESP8266/ESP32 (WiFi, billig €5-10)
  • Arduino mit WiFi Shield
  • Raspberry Pi Picos
  • Zigbee-zu-MQTT Bridge

Kapitel 4: Automation & Rules

Node-RED für visuell programmieren:

  • Wenn Tür öffnet → Licht anschalten
  • Wenn Temperatur > 25°C → Ventilator an
  • Morgens um 7 Uhr → Alle Lichter 50%

Kapitel 5: Dashboard & Monitoring

  • Home Assistant (beste Option)
  • Nodered Dashboard
  • Grafana für Visualisierung
  • Mobile App (iOS/Android)

Kapitel 6: Sicherheit & Skalierung

  • Authentifizierung (Username/Password)
  • TLS/SSL Verschlüsselung
  • Access Control Lists (ACLs)
  • Backup & Redundanz
