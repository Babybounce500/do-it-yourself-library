🖥️ Raspberry Pi Cluster

DIY Kubernetes Cluster mit RPi

Kapitel 1: Hardware Setup

Minimale Cluster-Config:

  • 3x Raspberry Pi 5: €120-180 (8GB RAM empfohlen)
  • 3x SD-Karten: 64GB, A2, UHS (€10-15 je)
  • Network Switch: 5-Port Gigabit (€15-25)
  • PSU: Multi-USB Netzteil (€20-40)
  • Gehäuse: Cluster-Case mit Lüftern (€25-50)
💡 Total: ~€300-400 für 3-Node Cluster

Kapitel 2: OS & Basis-Setup

Jedes Pi flashen mit Raspberry Pi OS Lite:

# SSH enablen für headless Setup # Static IPs: 192.168.1.10, .11, .12 # Hostname: rpi-master, rpi-worker1, rpi-worker2

Kapitel 3: Kubernetes Installation

K3s (leichtweight Kubernetes):

# Master Node: curl -sfL https://get.k3s.io | sh - # Worker Nodes: curl -sfL https://get.k3s.io | K3S_URL=https://192.168.1.10:6443 K3S_TOKEN=... sh -

Kapitel 4: Container & Deployments

  • Docker Images bauen (arm32v7 für ältere RPis)
  • Helm Charts für Deployments
  • LoadBalancer mit MetalLB
  • Persistent Storage mit Longhorn

Kapitel 5: Monitoring & Logging

  • Prometheus für Metrics
  • Grafana für Dashboards
  • Loki für Log Aggregation
  • AlertManager für Alerts

Kapitel 6: Production-Ready Cluster

  • High Availability (3+ Nodes)
  • Automated Backups
  • Rolling Updates
  • Network Policies & RBAC
