Kapitel 3: Autonomous Navigation

Drohnen fliegen allein:

GPS + Waypoints:
- Drohne fliegt zu Koordinaten automatisch
- Pre-programmed Route (Mission Planning)
- Return-to-Home bei Signalverlust
# ArduPilot Waypoint Mission from dronekit import connect, VehicleMode from dronekit_sitl import SITL # Verbindung zu Drohne vehicle = connect('127.0.0.1:14550', wait_ready=True) # Gehe zu Waypoint def goto_waypoint(lat, lon, alt): vehicle.simple_goto(LocationGlobal(lat, lon, alt))
Vision-basierte Navigation:
- Kamera + Computer Vision (OpenCV)
- QR-Code Verfolgung
- Objekterkennung (YOLO)

Kapitel 4: Computer Vision & Sensing

Die Drohne "sieht" und reagiert:

# OpenCV Person Detection import cv2 cap = cv2.VideoCapture(0) while True: ret, frame = cap.read() # Blob Detection oder YOLO # If person detected -> Drone goes there
Sensoren:
- IMU (9-axis): Bewegung tracken
- Barometer: Höhe halten
- Magnetometer: Kompass
- LiDAR/Ultrasonic: Hindernisse
