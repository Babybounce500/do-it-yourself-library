⛓️ Smart Contracts

Von Solidity zum Live-Contract

Kapitel 1: Blockchain & Smart Contracts Basics

Smart Contracts sind selbstausführende Verträge auf der Blockchain:

  • Ethereum: Erste Blockchain mit Smart Contracts
  • Solidity: Programmiersprache für Verträge
  • Gas: Gebühren für Transaktionen (in Wei/Gwei)

Kapitel 2: Solidity Programmierung Basics

Einfachster Smart Contract:

pragma solidity ^0.8.0;
contract HelloWorld {
  string public message = "Hallo Blockchain!";
  function updateMessage(string memory newMsg) public {
    message = newMsg;
  }
}

Kapitel 3: Token & ERC-20

Erstelle deinen eigenen Token:

ERC-20 Standard: Definiertname, Symbol, Balance, Transfer-Funktionen

Mit ERC-20 kannst du einen Token für dein Projekt erstellen und auf DEX (Decentralized Exchange) listen.

Kapitel 4: Development Tools & Testnet

  • Remix IDE: Browser-IDE für Solidity (remix.ethereum.org)
  • MetaMask: Wallet für Testnetzwerke
  • Faucet: Kostenlose Test-ETH von Sepolia/Goerli
  • Etherscan: Blockchain-Explorer zum Debuggen

Kapitel 5: Contract Deployment

Schritt-für-Schritt Deployment:

  • Contract in Remix schreiben
  • Compile (Check auf Fehler)
  • Auf Testnet deployen (kostenlos)
  • Bei Etherscan verifizieren
  • Auf Mainnet gehen (echte Kosten)

Kapitel 6: Sicherheit & Best Practices

  • Reentrancy-Attacken vermeiden
  • Input-Validierung
  • Integer Overflow/Underflow
  • Audits für Production-Contracts
  • Pausing-Mechanik für Notfälle
