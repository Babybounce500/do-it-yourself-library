Kapitel 1: Wallet-Typen

Nicht alle Wallets sind gleich sicher:

Hot Wallet
(Metamask, Trust Wallet)		 Internet-verbunden. Schnell aber weniger sicher. MAX: €1.000 ⚠️ Gefahr
Hardware Wallet
(Ledger, Trezor)		 Private Keys offline. Gold-Standard. €50-100 ✓ Best Practice
Paper Wallet
(Private Key ausgedruckt)		 Maximum sicher aber unbequem. Nur für langfristig Hold 💎 Langzeit
Exchange Wallet
(Coinbase, Kraken)		 Convenient aber nicht dein Schlüssel = nicht deine Coins! ❌ Riskant
✅ Sicherheits-Strategie: Hodl 90% in Hardware Wallet, Trading 10% in Hot Wallet

Kapitel 2: Seed Phrase - Dein privates Backup

# DIY Wallet Security # Hardware Wallet €50-100 # Ledger Live €0 (free) # Cold Storage €0 # Backup Tools €15 # Documentation €0 # Total: €65-115 secure setup

Die 12 oder 24 Wörter sind dein Master-Schlüssel:

❌ Häufige Fehler (Tausende Coins verloren!):
  • Seed Phrase digital speichern (Cloud, Screenshot)
  • Online teilen oder screenshot
  • In einem einzigen Ort lagern
  • Jemandem "nur zum Testen" geben
✅ Richtige Verwaltung:
1. Aufschreiben: Mit Stift auf Papier oder in Metall-Platte gravieren
2. Mehrteilig: Teile die 24 Wörter auf mehrere Orte (Safe, Familie, Verwalter)
3. Geheim: Niemand außer dir sollte es sehen
4. Backup des Backup: Mehrere physische Kopien an sicheren Orten
🔐 Pro-Setup: Trezor mit PIN + Passphrase (zusätzliche Sicherheitsebene) + Seed Phrase in 2 Tresoren

Kapitel 3: Häufige Angriffsvektoren

Wie Hacker dich angreifen:

1. Phishing (80% der Hacks)
- Gefälschte Websiten (uniswapp.com statt uniswap.com)
- Sie fragen: "Connect Wallet?" → NUR auf offiziellen Sites!
- Discord/Telegram Impersonatoren fragen nach Seed Phrase
Schutz: Lesezeichen auf echten Sites setzen, Domain doppelt checken
2. Smart Contract Exploits
- "Neue Yield Farm 500% APY" - Scam zu 99%
- Rugpulls: Entwickler stehlen Likidität
Schutz: Code audits checken (auf certik.io), unbekannte Token nicht joinen
3. SIM-Swap Angriff
- Hacker "übernehmen" deine Telefonnummer
- Sie resetten deinen Exchange-Account
Schutz: 2FA mit Authenticator App (nicht SMS!), PIN bei Telefonanbieter
4. Keylogger & Malware
- Dein Computer ist gehackt → Browser-Extension stiehlt Private Keys
Schutz: Krypto nur auf sauberer Hardware, Hardware Wallet use

Kapitel 4: Setup für totale Anfänger

Schritt-für-Schritt sichere Krypto-Verwaltung:

Phase 1: Cold Storage Setup (1 Std)
1. Ledger Nano S Plus kaufen (~€50)
2. Device initialisieren (auf offizieller Site ledger.com)
3. 24-Wort-Seed aufschreiben (NICHT digital!)
4. PIN wählen (6+ Ziffern)
5. "Seed Phrase Backup Verification" durchmachen
Phase 2: Seed Phrase Backup
1. Nimm ein leeres Blatt oder Metal-Backup-Platte
2. Schreib alle 24 Wörter auf (Reihenfolge MUSS stimmen!)
3. Foto des Backups? NEIN! Nur physisch.
4. Backup in Safe #1 lagern
5. Zweite Kopie zu vertrauensvoller Person oder Safe #2
Phase 3: Bitcoin/Ether empfangen
1. Ledger Live öffnen, "Ethereum Account" erstellen
2. "Receive" klicken
3. Device MUSS die Adresse bestätigen (um Phishing zu verhindern)
4. Diese Adresse an Exchange (Coinbase, etc.) kopieren
5. Kleine Menge senden als Test

Kapitel 5: DeFi sicher nutzen

Dezentralisierte Finance = mehr Kontrolle = mehr Verantwortung:

DeFi Aktivitäten: Swaps, Staking, Yield Farming
  • Swaps (Uniswap, Curve): Immer 0.5% Slippage setzen, Contract nicht unbekannt
  • Staking: Etablierte Pools (Aave, Curve). Neue Pools = 80% Scam-Rate
  • Yield Farming: <25% APY ist normal. >100% = vermeide!
❌ Absolute No-Go:
- "Connect Wallet" auf unbekannten Sites
- Discord DMs antworten die nach Private Keys fragen
- "Verified" Badge = bedeutet NICHTS (kostet nur €5 auf OpenSea)
- NFTs als Investment (99% Totalverlust)
# Metamask Smart Contract Interaction - IMMER checken: 1. Adresse der Site: uniswap.org (nicht .com!) 2. Approval Amount: Auf genauen Betrag setzen (infinity = Gefahr) 3. Gas Price: Mit Etherscan vergleichen (nicht zu hoch!) 4. Contract Code: etherscan.io - Code-Audit suchen

Kapitel 6: Notfall-Plan & Recovery

Was wenn etwas schiefgeht:

Szenario 1: Deine Hot Wallet ist gehackt
1. Hardware Wallet: Keine Sorge, deine Coins sind sicher
2. Hot Wallet Adresse auf Blacklist? Nicht schlimm, tu ein neues auf.
3. Recovery: Neue Hot Wallet erzeugen, von Hardware neu senden
Szenario 2: Du hast Seed Phrase verloren
1. Coin-Gewinne sind NICHT verloren (neue Device mit neuem Seed)
2. Alte Coins in alter Adresse sind weg (können nicht bewegt werden)
3. KEINE Firma kann dir helfen (das ist das Feld von Krypto)
→ Deshalb mehrere Backups!
Szenario 3: Du möchtest Geld zurück (z.B. nach Scam)
1. Blockchain Transaktionen sind unwiderruflich
2. "Hacker Recovery Services" sind auch Scams
3. Report to authorities ist Lehre für andere
→ Vorsicht ist besser als Nachsicht!
🆘 Notfall-Checkliste zum Ausdrucken:
- Hardware Wallet PIN merken?
- Seed Phrase Backups an 2+ Orten?
- Kontakt: Ledger Support (kein privater Keys gefragt)
- Krypto-Versicherung? (für >€50k, optional)
