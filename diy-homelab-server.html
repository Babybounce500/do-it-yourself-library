🖥️ Homelab Server

Cloud-Dienste selbst hosten

Kapitel 1: Hardware Setup

Was brauchst du?

Budget-Optionen:
- Option 1 (€80-150): Raspberry Pi 5 + Case + SSD (für leichte Workloads)
- Option 2 (€200-400): Alte Laptop/Mini-PC + SSD (Medium Workloads)
- Option 3 (€600+): Dedicated Server (Enterprise)
Was brauchst du sonst:
- Ethernet-Kabel (nicht WLAN!)
- 24/7 Stromversorgung (UPS optional)
- Linux OS (Ubuntu Server kostenlos)
- DDNS Service (für externen Zugriff)

Kapitel 4: Sicherheit & Backup

Sicherheit ist wichtig!

Security Must-Haves:
- SSH Key-Only (kein Passwort)
- UFW Firewall: nur notwendige Ports öffnen
- SSL Zertifikat (Let's Encrypt, kostenlos)
- Regular Backups (extern!)
- 2FA für alle Dienste
# Firewall Setup sudo ufw default deny incoming sudo ufw default allow outgoing sudo ufw allow 22/tcp # SSH sudo ufw allow 80/tcp # HTTP sudo ufw allow 443/tcp # HTTPS

Kapitel 5: Externes Zugreifen

Zugriff von überall:

Methoden:
1. DynDNS: Domain + DDNS Service (free: duckdns.org)
2. Reverse Proxy: Nginx/Traefik (sicherer)
3. Wireguard VPN: Verschlüsselter Zugang
4. Cloudflare Tunnel: Kein Port-Forwarding nötig
⚠️ Sicherheit: Hosting von zuhause = ISP throttling + IP-Bans möglich. Alternative: VPS (€5-10/Monat)
