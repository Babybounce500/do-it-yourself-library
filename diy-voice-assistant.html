Alexa/Google Home Alternative bauen

Kapitel 1: Hardware & Mikrofon

Minimales Setup:

  • Raspberry Pi 4 (4GB): €50-80
  • USB Mikrofon: €10-30 (oder ReSpeaker Array)
  • Speaker: Bluetooth oder 3.5mm €15-50
  • Netzteil: 3A USB-C €10
💡 Total: ~€85-150 für vollständigen Voice Assistant

Kapitel 2: Speech Recognition (STT)

Options:

  • Offline: PocketSphinx (lokal, weniger genau)
  • Online: Google Cloud Speech-to-Text (kostenlos mit Credits)
  • Hybrid: Whisper AI (OpenAI, offline fähig)

Kapitel 3: Wake Word Detection

Immer zuhören auf:

  • Porcupine: Wake-Word Detection (€0 personal, €99 kommerziel)
  • Snowboy: Kostenlos
  • Custom Modelle trainierbar

Kapitel 4: Natural Language Processing (NLP)

Intent Recognition:

# Beispiel: "Spiele Musik ab" intent = "play_music" device = "living_room_speaker"
  • Rasa: Open-Source NLP Framework
  • OpenAI API: Für komplexe Anfragen

Kapitel 5: Text-to-Speech (TTS)

  • gTTS (Google): Kostenlos, Cloud-basiert
  • Pico TTS: Offline, Raspberry Pi
  • MaryTTS: Open-Source alternative

Kapitel 6: Smart Home Integration

  • Home Assistant Integration (MQTT)

  • Custom Skills entwickeln
