Kapitel 1: Machine Learning Basics

Kapitel 4: Neuronale Netze bauen

Einfaches Dense Network mit Keras:

from tensorflow.keras import Sequential
model = Sequential([
  Dense(64, activation='relu', input_dim=10),
  Dropout(0.2),
  Dense(32, activation='relu'),
  Dense(1, activation='sigmoid')
])
model.compile(optimizer='adam', loss='binary_crossentropy')

Kapitel 5: Training & Optimierung

  • Epochs: Anzahl der Durchläufe
  • Batch Size: Datenmenge pro Iteration
  • Learning Rate: Wie schnell Gewichte anpassen
  • Validation Split: Train/Test Split
  • Early Stopping: Übertraining vermeiden

Kapitel 6: Model Deployment

Trainiertes Modell speichern & nutzen:

model.save('my_model.h5')
# Später laden:
from tensorflow.keras.models import load_model
loaded_model = load_model('my_model.h5')
prediction = loaded_model.predict(new_data)
