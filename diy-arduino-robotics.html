🤖 Arduino Robotik

Von der Platine zum funktionierenden Roboter

Kapitel 1: Arduino Basics

Arduino ist ein Open-Source Microcontroller:

  • Arduino Uno: €25-30, perfekt zum Starten
  • Arduino Nano: €8-12, kompakt
  • Arduino Mega: €35-40, viele I/O Pins
🎯 Anfänger-Projekt: LED-Blinker mit Arduino Uno

Kapitel 2: Programmierung mit Arduino IDE

Einfacher Code:

void setup() {
  pinMode(13, OUTPUT);
}
void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}

Kapitel 3: Sensoren & Motoren

Grundkomponenten:

  • Distanz-Sensor: HC-SR04 (€2-3)
  • Motor: DC-Motor + L298N Driver (€5)
  • Servo: MG996R für Drehbewegungen (€3-5)
  • Gyro/Beschleunigung: MPU6050 (€3-4)

Kapitel 4: Roboter-Plattform bauen

Einfacher 2-Rad Roboter:

Benötigt: Arduino Nano + 2x DC-Motor + Räder + Batterie + Distanz-Sensor

Der Roboter kann sich selbst steuern: fährt vorwärts, erkennt Hindernisse, dreht ab.

Kapitel 5: Autonome Bewegung & Logik

Programmiere Bewegungsmuster:

  • Sensor-gesteuerte Bewegung
  • Hindernis-Erkennung
  • Automatische Pfadverfolgung
  • Fernsteuerung via Funk (nRF24, Bluetooth)

Kapitel 6: Erweiterte Projekte

  • Roboter-Arm mit Servo-Steuerung
  • Linienverfolgung (3-5 IR-Sensoren)
  • Sumo-Roboter (2 kämpfende Roboter)
  • Smartphone-Steuerung via Bluetooth

💡 PRO-TIPPS & TRICKS

🎯 Tipp: Serial Debugging ist dein bester Freund

Problem: Roboter verhält sich seltsam, du weißt nicht warum

Lösung: `Serial.println()` benutzen um Sensor-Werte zu drucken → Debug Mode!

❌ Fehler: Motor-Pins ohne Resistor

🔧 TROUBLESHOOTING
